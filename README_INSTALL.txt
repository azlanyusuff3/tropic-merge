MONSTER ISLAND v18.4 - MONSTER MERGE + MONSTER MATCH ELEMENTAL POWERS

Play: https://azlanyusuff3.github.io/tropic-merge/

Only two games appear on the home screen:
- Monster Merge: original drop and merge game, unchanged.
- Monster Match: Classic Endless 8x8 with Match-5 EVOLUTION and five special powers.
  Bubblo: Tidal Wave (two rows)
  Shadebub: Shadow Explosion (3x3)
  Groveling: Vine Strike (both diagonals)
  Lumiorb: Star Magic (all normal tiles of the swapped kind)
  Infernodon: Inferno Blast (full row + column)
  Tap an evolved monster to preview its ability; swipe/tap to activate.
  Evolved + Evolved = 5x5 MEGA BLAST; powers can chain together.
  Six base matching types, eleven monster identities, endless moves and auto-save.

Monster Sling is still HIDDEN, not deleted. Its levels and progress remain in
the repo. It is not downloaded in the standard offline pre-cache.

Install in Android Chrome > Add to Home Screen / Install app.
After a first online visit, Merge and Match are playable offline.
DO NOT clear the app/site data to update: that would delete local game progress.

Development: npm install; npx playwright install chromium; npm test.
Match suite: npm run test:match.
