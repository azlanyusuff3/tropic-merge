MONSTER ISLAND v18.3 - MONSTER MERGE + MONSTER MATCH EVOLUTION

Play: https://azlanyusuff3.github.io/tropic-merge/

The home screen offers two relaxing games:
Monster Merge: original drop/merge game, preserved without gameplay changes.
Monster Match: Classic Endless 8x8 match-3 with Match-5 EVOLUTION, five rare
monster identities, 3x3 explosions, evolved+evolved 5x5 Mega Blast, cascades,
Match-4 line blasts, hints and shuffle. All 11 monster identities are used,
without putting 11 normal colors on the board.

Monster Sling is HIDDEN, not deleted. Its game files, levels and progress
remain in the repository; it is excluded from the default offline cache.

Android: Chrome > Add to Home Screen / Install app.
After the first online visit, Merge and Match are available offline.
Never clear site data when updating; local saved progress would be lost.

Development: npm install; npx playwright install chromium; npm test.
Match-only: npm run test:match. Sling maintenance tests remain in npm test.
